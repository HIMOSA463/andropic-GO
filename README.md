# andropic GO

Приложение для Android, которое связывает **телефон, компьютер и Arduino (ESP32/ESP8266)** по Wi-Fi.

```
 Телефон (APK)  ──►  ПК (server.py)  ──►  Arduino (ESP)
        └──────────────────────────────────►┘   (можно и напрямую)
```

## 1. Получить APK (без Android Studio, прямо с телефона)

1. Создай бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузи в него содержимое этой папки (кнопка **Add file → Upload files**, перетащи всё, включая скрытую папку `.github`).
3. Открой вкладку **Actions → Build APK → Run workflow**. Через 3–5 минут сборка завершится.
4. Открой завершённый запуск, внизу в **Artifacts** скачай `andropic-GO-apk`, распакуй zip — внутри `andropic-GO.apk`.
5. Открой APK на телефоне и разреши установку из неизвестных источников.

Альтернатива: открыть папку в Android Studio и выбрать **Build → Build APK(s)**.

## 2. Запустить сервер на компьютере

```
python pc-server/server.py            # блокировка/сон отключены
python pc-server/server.py --actions  # разрешить блокировку и сон
```

Нужен Python 3.8+. Для точных CPU/RAM/батареи: `pip install psutil`.
Сервер напечатает адрес и 6-значный **код доступа** — они понадобятся в приложении.
Всё, что печатаешь в консоли сервера, приходит на телефон в «Чат».

## 3. Прошить Arduino

Нужна плата с Wi-Fi: **ESP32** или **ESP8266** (обычная Uno/Nano Wi-Fi не имеет).
Открой `arduino/andropic_esp/andropic_esp.ino` в Arduino IDE, впиши имя и пароль Wi-Fi, загрузи.
IP платы появится в Serial Monitor (115200).

## 4. Подключить в приложении

Обзор → **Найти в сети** → выбери ПК и плату → Опции → введи код ПК → **Сохранить**.
Если включить «Управлять платой через ПК», команды пойдут телефон → ПК → плата.

Телефон, ПК и плата должны быть в одной Wi-Fi сети. Трафик внутри локальной сети не шифруется (HTTP), поэтому не используй чужие общественные сети.
